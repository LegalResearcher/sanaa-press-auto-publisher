# ناشر الأخبار المجدولة لصنعاء برس

هذا المستودع العام يشغّل مهمة دورية مستقلة لنشر الأخبار التي أصبحت مستحقة في قاعدة بيانات صنعاء برس. يعمل كل 20 دقيقة، ويمكن تشغيله يدوياً من تبويب **Actions**.

## أسرار المستودع المطلوبة

أضف السرّين التاليين في **Settings → Secrets and variables → Actions** داخل هذا المستودع فقط:

| الاسم | الوصف |
| --- | --- |
| `SUPABASE_URL` | رابط مشروع Supabase لصنعاء برس. |
| `SUPABASE_SERVICE_ROLE_KEY` | مفتاح `service_role` لمشروع Supabase. لا تضعه في الملفات أو السجل. |

## منطق النشر

يستدعي سير العمل الدالة `publish_due_scheduled_posts` في قاعدة البيانات. تنشر الدالة الأخبار ذات الحالة `scheduled` التي حان موعدها، وتحافظ على موعد الجدولة كوقت النشر، ثم تزيل موعد الجدولة من السجل.

لا يحتوي هذا المستودع على أخبار أو صور أو بيانات حسابات أو مفاتيح وصول.
