# تدوير Gemini — صنعاء برس

يتبع تدوير النماذج والمفاتيح في صنعاء برس منطق حصاد اليوم: اختيار سلسلة نماذج حسب توقيت اليمن، ثم استنفادها عبر مفاتيح ومجموعات المفاتيح بالاتجاه المحدد للفترة.

## إعداد المفاتيح

أضف في GitHub repository **Settings → Secrets and variables → Actions → Secrets**:

- `GEMINI_API_KEYS`: قائمة مفاتيح مفصولة بفواصل، للتوافق مع الإعداد الحالي أو كمجموعة واحدة.
- `GEMINI_API_KEY_GROUPS` (اختياري): مجموعات مفاتيح. افصل المفاتيح داخل المجموعة بفواصل، وافصل المجموعات بفاصلة منقوطة.

مثال شكلي فقط، لا تستخدمه كمفاتيح حقيقية:

```text
GEMINI_API_KEY_GROUPS=key_a1,key_a2;key_b1,key_b2
```

إذا لم يُضبط `GEMINI_API_KEY_GROUPS`، يستخدم النظام `GEMINI_API_KEYS` كمجموعة واحدة. إذا ضُبطت المجموعات، تكون هي مصدر تدوير إعادة الصياغة؛ يستمر `GEMINI_API_KEYS` أيضًا في خدمة مسار embeddings الحالي.

## سلسلة النماذج واتجاه التدوير

- **النهار، 14:00–23:59 بتوقيت اليمن:** يبدأ من أول مفتاح في أول مجموعة، ويجرّب النماذج النهارية بالتتابع لذلك المفتاح؛ بعد استنفادها ينتقل إلى المفتاح التالي، ثم المجموعة التالية.
- **الليل، 00:00–13:59 بتوقيت اليمن:** يبدأ من آخر مفتاح في آخر مجموعة، ويجرّب النماذج الليلية بالتتابع؛ بعد استنفادها يتحرك عكسيًا عبر المفاتيح ثم المجموعات.

سلسلة النهار: `gemini-3.6-flash`، `gemini-3.5-flash`، `gemini-3.7-flash`، `gemini-3.5-flash-lite`، `gemini-3.1-flash-lite`.

سلسلة الليل: `gemini-3.1-flash-lite`، `gemini-3.5-flash-lite`.

عند استنفاد كل المفاتيح والنماذج المتاحة في تلك الفترة، يفشل طلب إعادة الصياغة بدل تكرار المحاولات بلا نهاية. تبدأ كل عملية تشغيل جديدة من نقطة البدء المناسبة لوقتها.
